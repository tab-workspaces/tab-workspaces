# Tab Workspaces

Tab Workspaces is a Chrome extension that organizes your browser tabs into workspaces and groups, keeps them in sync with Chrome's own tab groups, and suspends tabs you are not using to save memory.

This repository is the public home for the project's **issues**. The extension's source code is not published here. Use this repository to:

- report a bug,
- request a feature,
- follow what has been reported and what is being worked on.

## Reporting a bug

The easiest way is from inside the extension: open the dashboard, go to **Settings > Privacy**, and choose **Report a bug**. The dialog shows exactly what will be sent before anything leaves your browser. URLs, e-mail addresses and other free text are redacted, and nothing is sent until you review and confirm.

Reports created that way arrive here as issues with a support code. Some details (for example an optional contact address, or optional raw tab details you chose to include) are kept in a private store and are never posted in the public issue.

You can also open an issue by hand with the templates in this repository. Please do not paste page URLs, tab titles, passwords or anything else you would not want to be public.

## What belongs here

- Bug reports and feature requests about the Tab Workspaces extension.
- Reproduction steps, expected behavior and actual behavior.

## What does not belong here

- Personal data, account credentials or private page addresses. Issues in this repository are public.
- Support requests that need a private conversation. Use the contact option in the bug report dialog instead.

## Conduct

Issues and comments must stay civil. Abusive or spam content may be edited or removed.
